Estrategia de Pruebas Multinivel

Cuatro niveles de prueba diseñados e implementados a lo largo de tres sprints (mayo–julio 2026).

Pruebas Unitarias

Cobertura global del 95% sobre 13,419 líneas medibles. Suite del equipo: ~480 tests sobre servicios principales — SlugGenerator, SearchService, PageService, BookService, ChapterService, ApiTokenGuard y más.

✅ Completado — Sprints 1 y 2

Pruebas Funcionales

220 casos de prueba de caja negra (CPF-001 a CPF-220) distribuidos en 20 requisitos funcionales. Técnicas: Partición de Equivalencia, Valores Límite, Tabla de Decisión y Transición de Estados.

✅ Completado — Sprint 2

Pruebas de Integración

8 puntos de integración (IT-001 a IT-008) cubriendo los contratos de la API REST de BookStack. Cobertura del módulo API: ~98% tras PR #60 (ApiTokenGuard — tokens expirados, inválidos y usuarios no confirmados).

✅ Completado — Sprint 3

Pruebas de Sistema

6 flujos E2E (ST-01 a ST-06) evaluando los atributos de Seguridad y Usabilidad según el marco de Pruebas de Orden Superior de Myers. 60 casos · 59 PASS · 1 FAIL intencional (ST-D-01).

✅ Completado — Sprint 3

Pruebas de Aceptación (UAT)

16 escenarios de aceptación: 6 UAT (UAT-01 a UAT-06) + 10 complementos funcionales (CF-11 a CF-20). 124 aserciones en 32.53s. Tasa de aceptación: 100%.

✅ Completado — Sprint 4

Pipeline CI/CD Automatizado

5 jobs paralelos en GitHub Actions: unit-tests, integration-tests, system-tests, feature-tests y coverage-merge (phpcov). Cobertura consolidada: 95%.

✅ Completado — Sprint 4

⚠ Defecto detectado — ST-D-01

La eliminación lógica no limpia el índice de búsqueda. Al eliminar una página con SoftDelete, el indexador de búsqueda no se actualiza de forma sincrónica. El contenido eliminado continúa apareciendo en resultados de búsqueda hasta regeneración manual del índice. Detectado exclusivamente mediante pruebas de sistema E2E (nivel de prueba superior). Clasificado como deuda técnica del sistema base. El caso ST-01-05 permanece en estado FAIL como evidencia formal.

Testsuite Langosta

Suite del equipo aislada explícitamente en phpunit.xml: 55 archivos nativos de BookStack excluidos. Esto permite medir la contribución del equipo con precisión, independiente de las 1,802 pruebas nativas del sistema base.

Principio de Independencia

Todas las pruebas crean sus propios datos mediante asistentes internos y usan DatabaseTransactions para limpieza. Cero dependencias de siembra global. Requisito previo para ejecución confiable en entornos CI/CD limpios.

Descripción del Sistema Bajo Prueba

BookStack v26.05-dev — plataforma wiki de código abierto construida con PHP 8.2, Laravel 12 y MariaDB 11.4.

Organización jerárquica

El contenido se organiza en Estantes, Libros, Capítulos y Páginas, con jerarquía navegable y control de acceso granular a cada nivel.

Control de acceso por roles

Sistema RBAC con niveles Administrador, Editor y Visualizador. Permisos aplicables a nivel de libro, capítulo y página individual.

Búsqueda y exportación

Indexación de texto completo con filtros avanzados. Exportación en PDF, HTML, Markdown, texto plano y ZIP (libro completo).

API REST

API completa autenticada por token con soporte para CRUD de libros, capítulos, páginas, estantes y usuarios. Cubierta al ~98% por el equipo.

Revisiones y trazabilidad

Historial de revisiones por página con mecanismo de diff para comparación entre versiones. Auditado en el flujo ST-05.

Autenticación avanzada

Autenticación local, MFA/TOTP, LDAP, SAML y OAuth2. Ciclo de vida de tokens API con control de expiración y revocación.
